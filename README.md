# Momentum

A personal, local-first study and deep-work dashboard built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Local data

The first launch creates empty collections and default preferences only. Goals, subjects, chapters, sessions, notes, projects, planner events, reflections, check-ins, and settings are stored in IndexedDB. Use **Settings → Backup & restore** to export or import a JSON backup, or reset the workspace on this device. No account is needed.

## Included

- Dashboard with goals, focus metrics, daily rhythm, mood, and energy check-ins
- Study subjects and chapter progress overview
- Pomodoro, stopwatch, and custom focus timer with session ratings
- Daily timeline planner, analytics views, notes, and personal projects
- Global workspace search with `Ctrl/Cmd + K`
- Responsive dark UI with motion and keyboard dismissal
